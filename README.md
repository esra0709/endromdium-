## About the Study

This study compares the predictive performance of routine hematological inflammatory indices and clinical variables for distinguishing high-grade from low-grade endometrial cancer.

A prespecified elastic-net logistic regression model was evaluated using repeated nested cross-validation. Model performance was assessed using discrimination measures, bootstrap confidence intervals, permutation testing, and SHAP-based explainability analyses. Additional machine-learning classifiers were evaluated as exploratory analyses.
